# Code of Conduct

Participants in this project are expected to:

- Discuss the work, not the person.
- Treat others with courtesy regardless of background or experience level.
- Accept technical disagreement and settle it with evidence.
- Refrain from harassment, personal attacks, and publishing others' private information.

Maintainers may remove comments, commits or contributors that violate these rules.
Report conduct problems privately to the maintainers through the contact listed in
[SECURITY.md](SECURITY.md).
