# SHA-256 measurements, 2026-11-06

Host: Ryzen 7 5800X (sha_ni, avx2, bmi2), GCC 16.2.1 -O3, OpenSSL 3.6.5. One run per configuration.

## Correctness

- `build/test_sha256`: FIPS 180-2 vectors (empty, "abc", 448-bit, 1,000,000 x "a") through the dispatched kernel; scalar vs SHA-NI on every length 0..4096: 0 mismatches; streaming in chunk sizes 1..130 equals one-shot. 7/7 checks.
- `build/test_sha256 FILE...` on 18 random files of 0, 1, 111, 112, 113, 127, 128, 129, 239, 240, 255, 256, 257, 1000, 65535, 65536, 65537 and 1048577 bytes: identical to `openssl dgst -sha256`.

## Throughput

Command: `build/bench_sha256 256 5` (256 MiB, 5 repeats, kernels interleaved), then `openssl speed -seconds 2 -bytes 16384 sha256`.

```
buffer 256 MiB, 5 interleaved repeats, sink 00000000
scalar  GB/s  min 0.393  median 0.395  max 0.398
sha-ni  GB/s  min 2.369  median 2.369  max 2.374
sha256         2356455.56k
```

A first run the same day gave scalar median 0.391 and SHA-NI median 2.356 GB/s (min 2.274, max 2.365), OpenSSL 2.342 GB/s. SHA-NI is 6.0x the scalar kernel and on par with OpenSSL (1.005x). Multi-threaded throughput has not been measured.
