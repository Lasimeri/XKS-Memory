# Count-based semantic model, first measurements, 2026-11-06

No neural model: co-occurrence (harmonic window 5, deterministic subsampling t = 1e-4) -> PPMI with context distribution smoothing (0.75) -> randomized SVD (rank 128, oversampling 16, 4 power iterations, CholQR2, Jacobi) -> word vectors (U + V) Sigma^0.5, row-normalized -> SIF memory vectors (a = 1e-3) minus the first principal component (Levy et al. 2015; Arora et al. 2017; Halko et al. 2011; sources in docs/RESEARCH notes).

## Build on the private-notes store (361 notes, 2,856 memories)

Command: `build/xksm semantic STORE` (CPU, 8-thread pool, Ryzen 7 5800X).

| Stage | Seconds |
|---|---|
| tokenize (545,209 tokens, vocabulary 16,972 at min count 2) | 0.040 |
| co-occurrence (2,139,188 distinct pairs) | 0.163 |
| PPMI (1,912,601 non-zeros) | 0.334 |
| randomized SVD | 3.314 |
| memory vectors (2,856) | 0.010 |
| store | 0.064 |
| total | 3.925 |

The SVD is 84 % of the build: the part to move to the GPU (OpenCL).

kw      25 queries  recall@1 0.880  recall@5 0.960  recall@10 1.000  MRR 0.920

- The semantic vectors carry real signal (term-matching queries: recall@1 0.840 alone) but do not beat BM25 on paraphrases (recall@10 0.320 vs 0.440); fusion is about equal to BM25 alone.
- Diagnosis: of the 139 distinct words in the paraphrase queries, 124 are in the model vocabulary, but the 15 missing ones are the content words that carry the questions (196 query tokens, 181 known, the known ones mostly function words). Distributional statistics cannot relate words the corpus never contains.
- The missing words are of two kinds: morphological variants of words the notes do contain (addressable with subword composition, no external data) and true synonyms (need general-language text).
- Tuning was not done; with 25 paraphrase queries and no held-out set, any tuning would fit this query set.
