# Agent harness memory: measurements, 2026-11-06

Ryzen 7 5800X (8 cores), 32 GB, NVMe, Linux 7.3. Store: a backfill of 66 Claude Code
transcripts into a scratch store (aggregate numbers only; no content is reproduced here).

## Backfill

`xksm transcripts` (66 files, 1.35 GB, 320,503 lines): 35.96 s wall, 37.36 s user, max RSS
1.43 GB, 0 unparseable lines; 11,516 dialogue + 84,677 trace turns = 150,951 memories
(`claude-code` 15,614, `claude-code-trace` 135,337), 150,934 embedded (the 17 without a
vector contain no word known to the table), word-vector table built from all 150,951
(vocabulary 152,574), 57 sessions, store 628,756,480 bytes. The time includes the table build.

## Precision checks

- Port expansion through int8 candidates (256) + exact f32 rerank vs the f32 scan: the
  expansion trace of all 50 evaluation questions is byte-identical (642 pairs).
- Hybrid + port v2 metrics with the snapshots: identical to before (term MRR 0.860,
  paraphrase MRR 0.213 with function words kept).
- Function words dropped (D26): term MRR unchanged; paraphrase MRR 0.224 -> 0.322 (BM25),
  0.206 -> 0.272 (hybrid), 0.213 -> 0.251 (hybrid + port v2), paraphrase recall@10 of the
  default 0.480 -> 0.520.

  a placeholder code word that only the first session contained, from the injected recall;
  prompts, replies, the `ToolSearch` and MCP tool calls and the tool result were stored with
